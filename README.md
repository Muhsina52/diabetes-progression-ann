# Diabetes Progression Prediction Using ANN

This project uses an Artificial Neural Network to predict diabetes progression using the Scikit-learn diabetes dataset.

The project includes data preprocessing, exploratory data analysis, ANN model training, evaluation using MSE and R² Score, and model improvement experiments.

**Tools used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow and Keras.
